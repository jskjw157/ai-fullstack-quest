# UI/UX 산출물

AGY(Gemini 3.8 Flash / high)가 만드는 UI·UX 명세를 이 디렉터리에 둡니다. 이미지 한 장이 아니라
다음이 함께 있어야 구현 담당이 그대로 작업할 수 있습니다.

- 사용자 흐름과 화면 우선순위
- 컴포넌트 구조와 디자인 토큰(색·간격·타이포)
- 빈 목록·로딩·오류·저장 실패·중복 클릭 상태
- 데스크톱과 360~390px 좁은 화면 동작
- 키보드·포커스·대비·동작 줄이기 요구사항

권장 파일명: `docs/design/<feature>.md`

AGY는 별도 worktree에서 작업하고, 구현 코드는 별도 승인 전에는 이 디렉터리에 만들지 않습니다.
구현은 Amp low가 `amp/<slug>` 브랜치에서 담당하고, DB·인증·AI 외부 호출·배포 변경은 구현 전에
Amp medium 설계 리뷰를 거칩니다.
